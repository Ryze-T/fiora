# 实验室：{slug}

目标 sink：`{sink}`（源文件 `{file}`）· 语言：{lang}

## 铁律（每次实验都要过一遍）

1. **真实代码**：漏洞函数必须从真实源码加载（只读挂载仓库）；
   只桩化非漏洞重依赖（torch/zmq/云 SDK/重型 IO），桩边界写在实验记录里。
2. **canary 无害载荷**：只写标记文件/回调，不取数据、不落 shell。
3. **正控往返**：正常数据路径必须验证通过——证明拦截缺失是安全缺陷，
   不是测试假象（如：正常 wrap/unwrap 等值校验）。
4. **一次性容器**：`--rm` 即用即毁，实验完 `docker rm -f`。
5. **证据三件套**：环境声明（真代码/桩化边界）+ 实测输出（原样）+ 结论分级
   （live-prove > trigger-prove > code-proof），不夸大。

## 运行

```bash
bash run.sh          # 构建镜像 + 跑实验 + 销毁容器
```

## 判读

- `[RCE ]` / `[PASS]` + canary 写入 = 触发成功（trigger-prove）
- `[BLOCK]` = sink 有防护，记录防护语义（如 weights_only / 白名单）
- `[ERR ]` = 失败，把终端输出贴回审计对话定位（不要静默改实验）
